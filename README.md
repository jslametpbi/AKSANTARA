# AKSANTARA — Aksara to AI: Nusantara English Futures

Static GitHub Pages app. Upload all files in this folder to a GitHub repository and enable Pages from the main branch.

## Features
- Premium landing page and dashboard
- Design philosophy and visual-structure boards
- 38 province hotspots with automatic QR update
- Integrated English skills module
- Voice Atlas with speech synthesis and simulated intelligibility feedback
- AI Tutor simulation without API key
- QR Station with PNG download
- Professional dossier gallery
- Admin lock/unlock console protected by owner PIN

## Deployment
1. Create a new GitHub repository.
2. Upload `index.html`, `README.md`, and the `assets` folder.
3. Go to Settings → Pages.
4. Select branch: `main`, folder: `/root`.
5. Open the GitHub Pages link.
